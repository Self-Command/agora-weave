## 1. 独立审阅的执行

根据已安装 Superpowers brainstorming 的 `builder-check-prompt.md`，派发一名新的软件工程审阅者，只读取当前 PRD，从“必须据此制定方案、不能再询问撰写者”的角度提出会实质影响功能、隐私或计划的问题。要求跳过明确留给工程方案的选择、常规实现细节和文字挑剔。

审阅返回 6 项重要问题：5 项已在文档中标为未决，1 项为新发现的编辑审核版本展示缺口。原有未决已经被记录，不等于已经解决。独立审阅不是对已实现系统的测试，也没有确认供应商或法律条件。

收到用户三项回答并修订后，同一独立审阅者再次只读复核这些修改，确认 EDIT-03 / AC-37、WEB-05 / AC-27、DEL-02 / AC-10 及问题 / 建议状态准确落实答案，未发现遗留的相反规则或重要矛盾。其“nothing important left”结论仅针对本次三项修订，不代表其余待确认条件已经解决或整份产品已获批准。

第二轮 S13 答复同步为 v0.2 后，同一独立审阅者再次只读核对业务、参数、验收及 Q / D / S13，返回“本轮修改无重要冲突”。其确认私信、关注期限、链接、引用、收藏及市场 / 部署 / 开发方式均准确落实，未发现相反旧规则仍作为有效要求；Q-06 / Q-07 / Q-09 已关闭，Q-02 / Q-03 只保留剩余范围。该结论限于本轮文档修订，未验证实际部署或候选参数，也不替代产品负责人批准。

## 3. 本次核对和修订

以下是文档编制者实际核对的规则，不代表真实系统已经符合要求：

- 旧 Appwrite 选型由最新 Supabase 决定覆盖；不沿用旧部署、认证或通知能力假设。技术依赖版本不虚构为已锁定。
- 信息流使用推荐、关注、最新；侧栏 / 设置保留图标与文字；AI 扩展仅展示入口，真实附件等未加入已确认功能；认证示例不等于正式授予。
- 引用整体继承原帖资格，原帖不可用时附加文字一起隐藏；进行中投票结果只向已投且当前有权者提供；首票成功锁定原截止时间，提前结束另记录。
- 区分关注审批与私信请求，以及账号屏蔽、拉黑、会话免打扰和移除粉丝；各类结束 / 冷却独立，关闭审批不批量批准，拉黑不自动删除公共历史计数。
- 增补不同关联的访问矩阵：评论中间节点删除不级联删除他人有效回复；引用链从严继承，帖子串依赖首帖；媒体与历史版本不提供授权旁路。
- 明确普通业务不可用与作者恢复 / 治理证据保留的差别，避免恢复期提前毁掉唯一副本，也避免保留副本被普通入口读取。
- AI 撤权覆盖实质依赖来源的旧回答、后续上下文、标题和复制，不只移除链接；作者三项用途设置分别执行，不能通过更名绕过。
- 注销移除关注、点赞、收藏等个人互动，本人内容及转发 / 引用停止展示，计数按真实有效记录更新；匿名投票聚合与接收方私信保留另行处理。
- 严格敏感媒体逐请求鉴权；签名、CDN、客户端缓存与 JWT 分别验证；暂定 60 秒不能当已实现撤权证明。
- 保留五类管理员的最小权限、MFA / 再次验证、一次性初始化、受控恢复、证据授权和独立申诉；无第二名复核人不能自行当作完成复核。
- 供应商故障不跳 OTP、不自动审核通过、不暗换模型服务商；保留输入和提交状态，正常社区能力依其真实依赖继续运行。

D-01、D-02、D-04、D-05 在第二轮问答获采纳；D-03、D-06 在首轮获确认。六个编号全部保留用于追溯，当前均为已确认规则，不能再作为待决建议。

### 3.1 v0.2 用户答复的落实

- DM-02 明确默认有效关注者可直接联系，陌生人一条请求；无审批时成功关注即具备资格，接收设置和拉黑优先执行。
- DM-06 保留全部关闭前的请求至原期限，允许查看 / 删除 / 举报但不接受；重开不激活结束、过期或被拉黑阻止的旧请求，不重置有效期。
- DM-10 默认关闭已读回执，双方均开才互显，任一关闭后双方不显；本人未读不变。
- DM-09 / 11、DATA-03 及保留表落实单条删除的个人撤权；历史分页、重连、附件 URL、会话重现与备份恢复不能恢复已撤销访问。共享消息及证据各按独立资格保留，未扩大为替双方删除。
- SOC-04 和参数表确认关注请求有效期 30 天、拒绝 / 删除冷却 30 天、取消 / 过期冷却 7 天；私信候选期限不因此获确认。
- POST-02 及类型表确认最多 1 个链接预览，正文多链接与失败展示 / 复制保留；引用首版仅附文字，原帖不可用时含附文整条隐藏。
- INT-03 不公开收藏数量、列表及身份，覆盖公开 API、互动名单、搜索和 AI 检索。
- 第 1.5 节、AUTH-02、TECH-02、Q-02 与 AC-36 确认中国大陆 / 18 岁门槛 / 主动年龄声明 / 官方 Docker Compose 自部署；核验官方自部署文档并保留实际部署、安全、短信、Android 推送和上线条件。Studio 与 Kiranism 业务后台区分，自部署不默认获得托管云 CDN 能力。
- Q-03 及工程决定记录纯 AI 编码智能体开发，不预设传统人工团队；内测日期、月运行预算及其他投入仍未定，不承诺排期或删减范围。
- Q-06 / Q-07 / Q-09 关闭；Q-02 / Q-03 的已确认部分与剩余范围分开记录；D-01–D-06 均已采纳，新增 S13 来源。

本轮同步修订 AC-02 / 05 / 08 / 16 / 19 / 21 / 36，保留原编号与覆盖，未新增产品实现或声称实际系统验收已通过。
