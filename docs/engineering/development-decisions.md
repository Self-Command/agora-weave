# 开发决定与职责

本文汇总仍影响后续工作的用户决定，不证明业务通过。产品权威仍是 [PRD](../product/PRD.md) 和 [spec](../../specs/001-agoraweave-v1/spec.md)，路线及进度见plan/tasks，真实结果见[当前状态](current-development-state.md)。旧报告与工具可在Git历史查证。

## 产品与资源

- ED-05/06：业务数据集恢复初始目标RPO≤1小时、RTO≤4小时，须实测；安全删除/撤权账本必须追到当前watermark，无1小时丢失豁免。申诉不设硬截止，首响应/处理提醒初值3/7工作日，后台可配置，不自动结案；原处置人不能独自最终复核，无合格第二人保持待复核。
- 用户负责预算、日期、服务器、域名、短信、设备、签名/分发、正式制度/条款/帮助及部署运营。工程实际需要时说明用途、环境、最小权限和安全供给，不反复泛问预算，不把供给当验证通过。短信选阿里云；真实测试需合格签名、模板、凭据及获准接收对象。
- ED-08：分享逐路由/方法/投影白名单核当前资格，有权受限与无权读取区分；作者/目标收录状态取交集，与AI用途独立。正式资料保持不可变版本、发布/撤下及适用记录；展示和用户明确同意分开，不编造正式内容。
- ED-09/10：私信无向账号pair唯一pending；US1、US3实现前置US2。App本人偏好GET/PATCH部分更新保未列字段、CAS及幂等，PUT拒绝。匿名与登录分享都只用平台默认/页面内操作，不读写同步账号偏好。FR-113由播放器、设置及每个真实入口共同承担。
- 2026-10-17已批准基础运营分期：真实账号/运营身份→文字静态图片单帖及审核→最新流/详情/基础资料/点赞普通评论→举报拉黑申诉→必要运维。AI/MCP、私信、视频/GIF、投票/帖子串、复杂关系/搜索、分享Web、插件及高级控制台后交，需求保留，详见plan。
- 配置为已有FR-130–141/T141–T148义务。每批开放业务贯通“行为→key/默认/范围/修改权→后台位置/API→服务端和客户端消费→生效/回滚验证”。高级可视化控制台可后交，当前必要入口随业务交付；个人偏好、核心安全不变量和不存在的运行能力不变成管理员任意开关。

## 执行与验证

- ED-14：验收采用iOS/Android模拟器，不再等待采购真机服务。保最低/当前OS真实构建、交互、生命周期、权限、媒体及可执行辅助技术验证；不支持硬件项记not_applicable及风险，不记通过。见[模拟器契约](../../specs/001-agoraweave-v1/contracts/simulator-validation.md)。arm64交付与x86_64模拟器包继续区分。
- ED-17：允许Actions固定Cloudflare临时HTTPS隧道/一次性认证验证隔离dev/test，只传合成非生产数据，不购买资源；结束清理入口、临时凭据和资源，不扩大证据服务器用途或授权生产/真实消息。

## 2026-10-17文档精简与Spec Kit退役授权

用户明确要求新开实施子agent，按讨论方案改造文档、清理与实际业务无关或失效资料、卸载Spec Kit技能；保留核心规格、宪法、285任务ID及51勾选、业务/原型/基础设置和多agent规则，主agent复检后保存干净工作区及新窗口提示词。该授权包括已检查的过期项目生成器/模板/技能/重复流程报告，不包括有效测试或后续产品需求。

采用[OpenAI官方工作流文章](https://developers.openai.com/cookbook/examples/codex/iterating-development-workflows-with-codex)的文档职责：AGENTS长期指导，spec/plan目标与路线，tasks加有界批次说明承载实施，当前状态仅关键决定/真实证据。复用现有目录，不复制GOALS/PLANS，不新建harness/skill/validator/报告平台，不逐次编辑/提交重批。

宪法保持7.0.0，仅修执行归属。Spec Kit退役后直接编辑保留资料，不运行生成器或重生成任务。旧决定的一次性暂停、强制认证、再生成和云端视觉要求由现行政策取代；已删报告可在Git查证，不以过时统计推导当前状态。
