# 执行政策（ED-24 现行）

依据宪法7.0.0、[2026-10-17流程优化决定](workflow-optimization-decision.md)及[原型开发调研与最新批准](prototype-development-research-2026-10-17.md)。本政策集中承载执行细则；
AGENTS只维护入口与强制条件。既有SK spec/plan/tasks是唯一规格基线，直接维护当前实施；仅需求、范围、
架构实变时按需用SK。285任务ID、全部产品范围、已有代码和有效测试保留，不重生成整套规格。
SP、桥接、历史红链、准入收据、重复报告认证和归档回读平台不恢复，不另建执行框架。

## 生产业务与成熟能力

所有开发、修改和操作围绕真实生产项目与正式交付，真实业务、API和原生可用性优先。
除设计HTML外，不新增演示/展示进度页面、临时功能或代替集成的测试壳。隔离合成夹具及自动化测试服务
只用于真实产品验证，不成为产品功能；不删除有效断言来凑绿，不因历史证明不足重做健康代码。

Kiranism以固定版本完整官方源码为基线，保留官方布局、导航、主题、表格、表单和组件后替换真实业务；
现有空入口不是完整复用，须后续恢复模板。Supabase官方Compose/Auth/Postgres/Storage/Realtime等已有能力
完全复用，优先配置、官方接口和扩展点；底层变化须保最小可追踪补丁与升级说明。
许可/依赖不等于完整复用，不得裁模板为空壳再自行重做。必要组件复用统一token及原生映射，逻辑与UI分离。

## 阶段与日常反馈

按直接依赖推进每阶段：先完成该阶段后端，再集中实现该阶段全部已批准App页面、适用状态及真实API，
随后按阶段集中视觉、交互与集成复检。开发中仅必要目标测试和直接受影响回归；阶段复检后修复只回归
受影响行为，不逐页反复完整检查，不无故重复整批验证。等待原型、云构建或外部服务时继续独立工作。
主任务中的问答或更新指令处理后继续已授权工作；用户明确停止、仅讨论或禁止其他操作时按其边界执行。

真实API/DB/App运行支持功能结论；编译、静态检查、mock和截图不能单独证明业务/真实交互完成。
关键权限、安全、数据完整性和缺陷修复须有效测试。日常目标/影响回归，阶段集中验证，发布执行完整适用矩阵。
共享真实DB夹具串行执行；失败先区分实现、夹具、环境和超时，再窄范围复测，保留原失败日志。
失败、跳过、取消、未执行和环境故障不得写通过；完整任务范围才勾选，局部进度和未验证项分列。
业务成果按可验证小批提交，保留用户未提交成果；本轮流程优化不夹带既有未提交业务。

## 已批准的多 agent 分工

2026-10-17用户明确批准以下分工，按独立工作启用，单一小改动直接处理；不为使用多agent强行拆分。
主agent负责范围、架构、接口契约、依赖顺序、复杂授权/事务/并发问题、集成审查、验证取舍与交付；
复用开发者结果，审查差异、接口和风险，不重复逐行实现及全部已通过检查。

| 角色 | 显式模型与推理等级 | 工作边界 |
| --- | --- | --- |
| 后端开发 | `gpt-6.1-sol` / `high` | 按明确模块实现服务端、迁移与目标测试；独立模块可由两名同配置开发者并行 |
| App开发 | `gpt-6.1-sol` / `high` | 仅实现已批准页面/状态、真实API与原生适配 |
| 后台开发 | `gpt-6.1-sol` / `high` | 完整复用官方模板，接真实后台业务 |
| UI复检 | `gpt-5.6-luna` / `xhigh` | 独立只读真实客户端复检，不参与开发；具体边界见下节 |

2026-10-17用户最新要求：所有开发子agent（含代码复检）统一显式使用 `gpt-6.1-sol` / `high`，取代此前开发角色的模型选择。
复杂子任务由主agent处理或按同一配置委派；启动及恢复均核对实际模型，不继承主模型、不默认选择或自动回退。
开发固定模型或固定UI配置不可用须报告，不能因总允许名单中另有模型而自行替换。
角色是职责，不是同时常驻的实例。本会话工具最多4个活动agent（含主agent），实际以工具上限为准；
通常主agent加两名开发者，按复检需要释放名额，不同时启动全部角色、不递归扩张团队。

先完成本阶段后端实现及适用目标验证；后端可并行拆不同模块。此后App与后台可分文件并行；
App另须对应具体原型获人明确批准，后台依完整官方模板推进，不因App原型待批而停止独立后台工作。
最后在集成版本由UI角色集中实际复检，开发者修复后同角色优先复测受影响项，再交用户验收。
等待页面批准或外部结果时继续无依赖工作，不扩大产品范围或跳过未完成项。

每次委派给最小必要上下文：仓库根、宪法路径并要求先读遵守，既有任务ID、范围/文件、接口契约、
预期行为、适用测试命令与批准边界；独立开发不继承完整会话。返回改动文件、实际测试、风险和阻塞，不堆原始日志。
同一文件同一时间仅一名写者；重叠修改串行或隔离工作树后由主agent集成，先保全现有未提交成果。
共享契约、依赖/锁文件、迁移编号、公共配置、规范与工作流变更由主agent协调，规范集中编辑与同步。
工作树只隔离源码，不能隔离共享DB、夹具、H盘运行副本、Metro、模拟器或浏览器会话；这些资源同一时间仅一名操作者，
共享DB测试串行，切换运行源码须先交接，不能同时同步不同树覆盖运行区。UI复检用稳定集成版本。
不新增调度平台、认证收据、任务集或重复报告；并行用于缩短独立工作的等待，不承诺总token一定减少。

## 页面批准与真实复检

先实际查看UI-SPEC、token和适用设计画面/交互。App和分享Web新增页面/设计变更先接入
`docs/design/prototype/index.html`同一导航、主题和组件，补必要状态并尽快展示给用户明确验收；
原型只保留视觉确认必要交互，不扩充演示状态机拖延真实开发。未批准只继续原型和独立后端。
设计不变的实现修复沿用已有批准，改变设计重新批准；共同组件有独立明确批准可先实现组件，不能冒充整页批准。
后台及其扩展直接以Kiranism完整官方模板为设计基准，免重画同款HTML，但新增/改UI后仍在实际后台检查。

App忠实还原已批准具体页面原型；同页、同状态、同主题和正常字体1.0对照，约390×844仅作适用参考，
保持内容布局、信息层级、文案语义、颜色、组件和操作一致；允许系统字体、安全区、键盘、触控及无障碍适配。
错页、缺内容、明显风格/层级偏离、遮挡及交互错误必须修复；细微字形/抗锯齿/换行或不改变设计意图的微小间距差异
记录为建议，不单独阻塞阶段。不得为了零像素差异破坏原生可用性，也不得借适配自行重设计；实质差异交用户决定。
独立UI角色按真实影响分类，每个问题给对应画面或操作证据；修复复测受影响项，不反复以轻微差异重开整批验证。
大字/读屏专项按风险单独检查，完成后恢复正常缩放；不让用户以专项画面判断日常视觉。

页面绑定记录见UI-SPEC与 `docs/design/page-registry.json`：具体页面、状态、设计版本、人的明确批准、生产入口、
实际组件路径，以及阶段适用整页原生/浏览器对照和交互验证。AI不能自批；CI仅查记录和路径，不证明美观或人的同意。
账号r2仍pending；基础组件已批准不授账号整页资格；后台模板政策批准不等于功能或页面验收通过。
无批准不得进行对应生产UI设计修改，无整页实际对照和真实交互不得勾页面完成。页面清单检查仅在实际生产UI变更、阶段完成或发布相关范围触发，不阻塞纯后端工作。

2026-10-17用户明确要求移除未按原型制作的旧呈现层：先保全当前成果，提取并保留有效业务逻辑/API/测试，
删除旧整页JSX和样式，保留已批准共享组件。无已批替代页时框架路由可暂时返回null，不能把空页说成产品完成。
页面清单保留pending设计批准，另记用户退役指令和移除路径；变更检查仅对实际删除与空路由放行，新增UI仍须设计批准，
退役页面不能通过阶段完成检查。后台恢复完整官方源码遵循既有模板基准；仅本机显式开发预览可看官方样例，
生产及未实现真实管理员身份/权限入口保持拒绝，不使用Clerk/keyless或假管理员，不外发Sentry数据。

每次UI检查/用户验收开始或展示时，给用户可查看的已确认可访问链接与路径，或App实际页面入口/深链及设备；
说明必要身份/导航，按需正常缩放截图/录屏，不外发秘密、不绕权限、不声称未核地址可用。
优先复用真实页面和原型，不增验收壳。阶段集中复检覆盖适用状态、浅深主题、键盘、安全区、触控、字体缩放和无障碍。

2026-10-17用户明确批准：阶段UI复检固定由独立专职子agent承担，显式使用 `gpt-5.6-luna`，推理等级 `xhigh`。
该角色不参与页面开发或修改业务代码；只读取适用规范、对应原型/官方模板、真实页面入口和必要验证资料，
独立检查整页视觉及实际交互，逐项给出差异、截图位置、复现步骤和未验证范围。主agent协调开发者修复，
同阶段优先由原复检agent复测受影响项，再交用户验收；不逐页反复整批检查。仅固定职责和配置，不假定同一实例跨窗口常驻。
AI复检不能代替人的原型批准或首次产品基准确认；无法调用该模型/推理等级时明确报告，不静默换模型或降低等级。

## 原生运行与平台适配

移动生产端保持Expo/React Native/Expo UI，不转移动网站或WebView。复用已安装开发包和常驻Metro；
普通JS/TS/样式用Fast Refresh，原生代码、依赖、config plugin、产物配置变化或开发包不兼容才云端重建。
所有APK/AAB/IPA在GitHub Actions编译，本机只下载、安装、运行和复检；发布构建按真实交付需要执行。
arm64-v8a用于真机测试/交付，x86_64用于电脑模拟器；不新增32位测试/构建，模拟器包不冒充ARM手机包。
最低系统与CPU架构独立核验，系统/权限/原生依赖兼容集中原生配置及适配层，不散入账号等业务规则。
关键页面首次完成、影响体验的原生变化、发布前按风险集中实际客户端复检；开发中适用截图对比筛查布局变化。

保留既有 `.agoraweave/local/{environment}/runtime` 私密资料、唯一开发容器组和数据卷，不创建重复环境。

## 授权与规范同步

普通可逆工程选择自主处理；范围、技术栈、安全隐私、费用、不可逆删除/高影响迁移/生产操作改变按宪法九取得
具体决定，只暂停依赖工作；沉默不能代批准。本会话首次/切树/规范变化运行Verify，未变复用结果，工具内置检查保留。
规范集中修改后同一变更运行 `sync-governance.ps1 -AllBranches`，所有登记树与分支一致后才业务实现/提交/交接；

post-commit/post-checkout钩子不能绕过；桌面树同为正式登记树。规范相同不推断各分支业务/测试相同。
历史决定与报告标历史，不覆盖现行入口；不得靠记忆或交接词替代同步与当前Git/代码检查。

子agent只允许gpt-6.1-sol、gpt-6-sol、gpt-5.6-luna，显式指定并核对实际模型，禁用继承/默认/回退到名单外或Astra；
固定开发与UI角色遵守上文指定配置，不据总允许名单自行替换。委派传仓库根和宪法路径并要求遵守，不能以技能默认流程降低这些规则。
