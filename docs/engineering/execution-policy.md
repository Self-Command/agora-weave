# 执行政策

依据[宪法7.0.0](../../.specify/memory/constitution.md)和[用户决定](development-decisions.md)。PRD/spec规定产品验收，plan规定技术与分期，tasks保285任务和真实状态。Spec Kit已退役，直接维护现有资料；不重生成任务，不恢复SP/桥接、强制逐行为TDD、历史红链、准入收据或另建执行框架。

## 交付与文档

按plan基础运营分期推进：真实账号/运营身份、文字静态图片单帖/审核、最新流/详情/基础资料/点赞普通评论、举报拉黑申诉及必要运维。后续产品需求保留。服务器、域名、短信及正式分发由用户搭建，缺资源只暂停依赖动作，继续独立实现/合成验证，不虚构真实短信或生产通过。

AGENTS保长期入口/边界；spec/plan/tasks不重复会话日志。[当前状态](current-development-state.md)只保交付源码/证据、未完成边界和下一批入口；重要长期决定写入决定汇总。需要多步骤/交接时在 `specs/001-agoraweave-v1/implementation/` 维护一份有界批次说明，链接既有任务，写目标、输入、依赖、文件范围、验收、实际命令及停止条件，简单修复可直接执行。批次执行记录只保实际命令/版本/结果/必要日志路径及剩余项，同一原始证据不重复转录。完整任务满足才勾选。

每阶段后端→集中获批App页面/状态与真实API→本地集中视觉/交互/集成复检。后端可按独立模块并行；依赖满足后App/后台按独立文件并行。等批准/服务/云构建时继续独立工作。除设计HTML，不新增演示产品页、进度页、临时功能或代替集成的测试壳；保有效合成测试。

完整复用固定Kiranism布局/导航/主题/表格/表单/组件及Supabase官方Compose/Auth/Postgres/Storage/Realtime；优先配置、官方接口与扩展点，底层补丁最小可追踪，不把依赖/许可冒充完整复用。

配置为现有FR-130–141/T141–T148义务。每批开放业务明确行为→key/默认/范围/修改权→后台位置/API→服务端/客户端消费→生效/回滚验证。必要入口随业务交付，高级控制台后置；个人偏好/核心安全不变量不变任意管理员开关，登记不算消费完成。

## 验证与交付

日常目标及直接受影响回归；权限、安全、数据完整性和缺陷修复须有效测试。逐行为TDD自主判断，编译/静态/mock/截图不能单独证明业务或真实交互完成。失败先分实现/夹具/环境/超时，保原失败，修复后窄复测；失败、未执行、跳过、取消和环境故障不记通过。

| 对象 | 责任 |
| --- | --- |
| 业务 | 单元/API/集成验证规则、当前权限、数据、并发、失败边界 |
| 控件 | 组件测试验证输入/点击调用动作参数；原生自动化验证真实输入、导航和反馈 |
| 视觉 | 独立UI角色以单主题对照获批设计/官方模板，仅检查布局、颜色、遮挡和可读性，不查功能、交互或重复dark |

各层引用适用结果，UI不重复整套业务审查；controller单测不冒充组件点击，截图不冒充设备操作。阶段用稳定集成版本集中验证，修复只复测受影响项；发布覆盖当前交付完整适用集合，后续产品正式验收责任保留。

复用健康结果须核源码、依赖、配置、输入及适用范围。只改自动化/Runner/发布脚本时先定向复验，不重复重建有效包/健康业务矩阵；影响未知才扩大。GitHub同run重跑仍为原SHA，修复新提交须运行修复版本。长构建前核工具链、资源、冻结输入、权限及产物路径；云端已有产物优先直接上传。有界等待/退避，无变化不重复轮询、读日志、写报告或为播报重跑命令。

## 已批准的多 agent 分工

主agent负责范围、架构、接口、依赖、复杂授权/事务/并发、集成、验证取舍与交付；复用已核实成果，不重复开发者实现及全部检查，单一小改直接处理。

| 职责 | 显式模型/推理 | 边界 |
| --- | --- | --- |
| 后端/App/后台开发、代码复检 | `gpt-6.1-sol` / `high` | 按明确文件/契约实现或复检，App限获批页，后台完整模板 |
| 独立UI复检 | `gpt-5.6-luna` / `xhigh` | 不参与开发，在真实客户端集中检查并复测受影响项 |
| 轻量协调自检 | `gpt-5.6-luna` / `medium` | 只给主控重复/等待/职责堵塞的简短建议 |

总允许名单仅gpt-6.1-sol、gpt-6-sol、gpt-5.6-luna，具体职责仍按表固定；显式指定，禁止继承主模型、默认/回退、Astra或名单外型号。启动/恢复核对工具配置；工具不暴露实际型号如实记未知，不以模型自称冒充核验。固定配置不可用报告，不静默替换。

每次派发前主控亲核现有原型、实现、任务、依赖与授权，只派缺失增量，禁止未经审阅就委派重复设计。优先复用可访问、同职责且配置匹配实例，未变规范复用已读记录。不可用、上下文过长、必要并行或独立审查才新建；开发者不独立审查自己，不假定跨窗口可访问。通常主agent加两开发者，服从工具上限，分批释放复检名额，不同时启动全部角色或递归扩张。

最小任务包含仓库根、宪法路径及遵守要求、既有任务ID、文件范围、契约、行为、目标命令和批准边界，新实例不继承完整会话；返回改动/实际测试/风险/剩余项。公共契约、依赖/锁文件、迁移编号、规范由主控协调，同文件单写者。DB/夹具/H盘运行副本/Metro/设备/浏览器串行交接，工作树不隔离这些资源，不同时覆盖运行区；规范集中同步。

主控可在同因连续失败两次、无证据重复检查、资源职责冲突、约15分钟无有效进展或自然交接时自检，正常长测试/外部等待/暂停除外。简单问题自行处理；需要独立视角才用固定协调角色只读最小近况，一轮1–2分钟、最多3条约300字，不改代码/DB/设备、不重跑测试、不递归委派。无法核实配置停止该次agent检查，主控继续直接判断，不阻塞授权工作。主控择1–2项可逆小调整，下次自然验证观察，不新增门禁/自检报告或证明节省比例的测试，不削弱独立复检/人的批准。

## 页面批准与本地复检

实现前实际查看UI-SPEC/token/具体原型画面与交互。App/分享新页或设计变化先加入统一HTML原型，明确页面/状态/版本并获用户批准；基础组件不授整页资格，已批设计直接复用不重画，设计不变修复沿用批准。后台直接使用完整Kiranism现有UI，无需另画原型，仍实际复检。账号r2五页/选择器全部状态/浅深已批准，精确版本见[页面登记](../design/page-registry.json)。

App同页/状态/主题、字体1.0对照，保持布局/层级/文案/颜色/组件/操作；允许字体、安全区、键盘、触控、无障碍适配。明显偏离、错页、缺内容、遮挡、功能问题必修；细微渲染差异记建议不单独阻塞，实质设计差异交用户决定。大字/读屏按风险专项，结束恢复正常缩放；空路由不算完成，不恢复假身份/Clerk/keyless或外发Sentry。

独立UI角色只对稳定版本的布局与样式按页面/状态采单主题整页图，与同主题设计组成可读拼图批量复检，保原图，疑点局部放大；不查功能或交互，不重复dark。功能与交互仍由业务、组件及原生验证完成，截图不代替实际操作。开始前确认源码、运行版本、入口和设备，采集期间不覆盖运行区/Fast Refresh。集中列必修项后定向修复复测；纯文档/未变页面不重开整批。给用户已确认可达链接/设备路径及导航，不暴露秘密。

视觉仅本地，云端不运行视觉/主题字号截图矩阵；Actions保构建、业务/接口/安全/并发、原生输入点击反馈生命周期HTTPS/Hermes，静态设计来源检查保留。页面完成须整页真实对照与交互，CI不证明美观/人类同意，首次实际产品基准仍用户确认。

源码留工作树，统一tools/dev/local.ps1内容增量同步至H:/Projects/AgoraWeave/development/workspace。保原私密runtime配置、唯一dev容器组和数据卷；dev/test/prod数据、凭据、副作用隔离。先Status按需Up，健康服务复用，缺依赖才显式Install，迁移仅显式Migrate，不自动重置seed。后台模板仅显式本机127.0.0.1预览，生产及无真实管理资格入口拒绝。具体命令见[quickstart](../../specs/001-agoraweave-v1/quickstart.md)和批次说明；共享DB串行，完整ci:core仅适用阶段/发布运行，不原地改已应用迁移，核依赖和摘要。

普通可逆工程自主处理；范围/栈/安全隐私、费用、不可逆数据/高影响迁移、生产操作按宪法九取得具体决定，仅暂停依赖动作。已授权资料清理不重复审批。
