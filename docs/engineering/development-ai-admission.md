# 开发审查准入

按 ED-11，当前 Codex 阅读实际代码、契约与 Actions 的真实报告／图像，分别记录代码和视觉审查。没有额外审查模型账号或独立模型调用。所有执行、采集、差异和记录验证仍在 Actions。

受审范围只含必要工程资料与合成数据。服务器只存证据；真实用户、生产资料、秘密与高权身份不交审查。每次审查绑定目标 SHA、受审输入和每张实际图像摘要、报告摘要、必需范围、当前会话、读取时间、findings、处置证据和无法判断项。新输入或 SHA 使旧记录失效。

审查记录不能自己授予 passed。Actions 下载校原件并验证记录绑定，实际交互、设备与无障碍检查独立必需。漏图、截断、未解决问题、unknown 和实际检查失败均阻塞。无业务壳不创建产品基准；首个产品候选须由用户确认具体摘要和覆盖范围。

当前接线由共享编排生成认证输入上下文，等待当前 SHA 和上下文摘要对应的私有记录，再在 Actions 校验 schema、输入及每图摘要、实际报告和覆盖。缺记录、传输失败、超时和过期记录均保留拒绝；接线存在不代替当前版实际审查。最新发现及其复检应记录于私有审查记录；最终门禁通过前不宣称 T018–T020 或 ci-ready 已完成。
