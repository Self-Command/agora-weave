## 输入、权限、事务与异常边界

正式资料使具技术能力者独立从零创建组织调试测试打包提交/授权发布/升停卸恢复排障，覆盖manifest/SDK公共类型API事件插槽/权限RLS/依赖配置迁移保留日志故障。文档随平台工具契约插件版本维护compat/弃用迁移，不以索引或内部函数替产品。

移动page/route/nav/menu/component/profile/detail/comments/feed/notifications/settings；后台menu/page/dashboard/operations/config/ai/plugins；后端API/DB扩展迁移RLS/事件任务通知/批准只读AI。声明可关联，重复命名冲突缺依赖错版拒不覆盖，有限树禁止eval/任意URL/SQL/身份覆盖；未公开能力需新增契约，native变化需构建。

通用样例A移动后台后端权限完整，B独立数据及受审共享读，不预置行业生产业务。只用正式发布文档工具从零真实双端/后台/backend/RLS/打包授权生命周期恢复，核心diff=0才闭环。Host媒体复用真实播放器，当前grant/资源及audience合法输入不增private偏好。

dev/test/prod的DB/Storage/账号凭据日志网络副作用真实隔离，非藏入口或行environment；测试默认不真发消息SMS推送不取生产私密数据，外部渠道需测试准入/费用/处理政策，失败不影响他环境插件。

所有写动作均应用公共CAS/operation/未知结果规则；失败保输入，当前资格变化不复用旧授权。后台动作继续逐操作/资源/env/MFA核验，控件启禁只作提示。

## 最小必要验证

1. 指定版本仅正式资料从零A/B三端包和客户端权限打包授权发布恢复，核心无diff，缺步骤不完整。
2. A→B/跨用户环境DB/API/Storage/Realtime/job/log/config/AI/备份负向及受审共享当前投影；租约到期拒。
3. Host全插槽冲突兼容旧端不崩溃，真实UI/媒体binding当前grant与合法输入，静态声明不代播放交互。

日常目标和直接影响回归，正式结论需真实客户端与隔离服务；后置/缺资源消费者保持未验证，编译、mock或截图不替业务通过。

## 完整需求行为

<a id="fr-142"></a>

- **FR-142**：平台必须提供正式维护契约，让开发者独立增加移动、后台和后端业务，不为每个插件改核心或复制项目；明确当前可扩展位置及需新增平台契约／原生构建条件，不用任意内部补丁当公开能力。（PLT-01；AC-43、AC-48）

<a id="fr-148"></a>

- **FR-148**：移动扩展必须覆盖页面／路由、导航／菜单、组件、主页、详情、评论、流、通知和设置位置，声明输入、可用能力、展示权、冲突／顺序、加载／错误／兼容；注册不授权限，旧端不崩溃、死路或误展示可执行动作。（EXT-01；AC-44、AC-47、AC-52）

<a id="fr-149"></a>

- **FR-149**：后台扩展必须覆盖菜单、独立页、仪表盘、运营、系统配置、AI 和插件管理；共用认证及逐操作角色授权，新增菜单不授管理员，管理员能查所属插件、状态和原因。（EXT-02；AC-44、AC-50、AC-52）

<a id="fr-150"></a>

- **FR-150**：后端扩展必须可受控申请业务接口、数据库扩展／迁移与数据访问策略、事件／异步任务、通知和批准只读 AI 工具；能力、依赖、数据范围安装时校验、运行时继续授权，不默认无限数据权力。（EXT-03；AC-44、AC-50）

<a id="fr-151"></a>

- **FR-151**：同插件三端声明、公共类型、接口／事件及兼容必须可关联检查；重复／命名冲突／缺依赖／版本不符明确结果，不静默覆盖；事件／任务关联插件、环境和请求，重复或重试不重复业务或通知。（EXT-04；AC-44、AC-48）

<a id="fr-165"></a>

- **FR-165**：正式开发文档必须覆盖从零创建、调试、测试、打包、部署、更新、卸载、排障，含规范、组织、清单、开发工具、公共类型、扩展／接口、事件、迁移、权限、依赖、兼容、配置、日志及数据生命周期，使具备技术能力者无需改核心完成扩展，不以简短导航页代替。（DEV-01；AC-48）

<a id="fr-166"></a>

- **FR-166**：必须交付官方模板、通用示例、生成工具、开发工具包／公共类型及接口文档，注明支持版本、生成内容、环境／限制；通用示例完整关联移动页、后台入口、后端业务与权限验证，名称／数量／形式留方案，不预置行业或当生产业务。（DEV-02；AC-48）

<a id="fr-167"></a>

- **FR-167**：文档必须与平台、工具、契约及插件版本共同维护，明确兼容表、变更／弃用和迁移说明，开发者辨别适用版本，不靠猜内部实现；邀请审核按首版责任执行，支持窗口与访问机制留方案。（DEV-03；AC-48）

<a id="fr-168"></a>

- **FR-168**：文档和工具必须提供本地高频开发与独立云端环境、真实前端预览/交互、受控测试账号/数据、权限声明/模拟、日志、故障模拟、自动验证、发布及恢复实践。开发者可选择本地隔离反馈，云端独立开发路径仍不要求先本地启动；单端／跨端结论须有对应客户端真实验证，Actions按需复验。（DEV-04；AC-48–49；ED-21）

<a id="fr-169"></a>

- **FR-169**：开发者首版交付必须以能从零完成通用跨端样例、权限验证、打包、经授权发布及恢复闭环判定，而非仅存在接口或文档；具体样例与资源方案须记录工程依据，不将受邀资格自动变成生产操作权。（DEV-01–04；AC-48–49）

<a id="fr-170"></a>

- **FR-170**：云端开发／测试与独立生产必须真实隔离业务数据、媒体、账号、凭据、日志及副作用，不能仅藏入口；受控独立数据不默认复制生产私信、草稿或用户信息。（TST-01；AC-49–50）

<a id="fr-171"></a>

- **FR-171**：开发者必须能在授权云端独立调试／预览移动、后台、后端及数据权限并执行单端、集成、回归、端到端和实际视觉／交互，使用受控账号／数据、请求／运行日志及故障模拟，不影响生产用户／插件。（TST-02；AC-49）

<a id="fr-172"></a>

- **FR-172**：测试令牌与权限必须限环境及插件，默认不改生产、不发真实消息／推送或影响真实用户；短信、通知、AI 等用明确测试通道／模拟管理费用和处理政策，必要真实外部测试须先满足准入，不让插件切生产凭据。（TST-03；AC-49–50）

<a id="fr-173"></a>

- **FR-173**：云端测试／预发布必须验证安装、启停、升卸、权限变化、依赖冲突、迁移失败、任务重试、前后兼容、资源异常、回滚与保留，并关联版本、配置和运行／视觉／交互证据；生产消费获批同版产物，不能验一个包换另一个发布，测试失败不损其他环境。（TST-04；AC-46–50、AC-51–53）

## US12旅程验收

1. **Given** 指定平台和文档版本，**When** 开发者创建扩展，**Then** 能找到契约、公共类型、模板／工具、配置、权限、兼容、迁移和故障指导，不需要修改核心源码。
2. **Given** 前端、后台和后端扩展声明，**When** 注册与调用，**Then** 关联和兼容可检查；冲突、缺依赖或无权操作明确失败，不覆盖另一插件。
3. **Given** 授权开发／测试环境和账号，**When** 独立预览、故障模拟、单端与全流程测试，**Then** 在云端取得真实页面及权限证据，数据、凭据与副作用不触达生产。
4. **Given** 插件 A 和 B 及不同用户，**When** A 访问 B 或共享资源，**Then** 仅声明且获批的受控共享返回当前用户有权数据；环境、日志、配置、恢复不能成为旁路。
5. **Given** 受邀开发者完成包，**When** 提交，**Then** 默认仅有提交权，不能自行认可审核、授予敏感权限、安装或生产发布。
