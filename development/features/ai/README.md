## 输入、权限、事务与异常边界

广泛问答/热门/自动推荐只取合规有效公开且满足用途/过滤；受限需有权主动选/作者用途许可/必要告知，self/草稿本人主动选并确认。私信证据管理记录待审限制删除旧版无通用AI选取入口；识别内部引用走来源规则，未识别粘贴不授文件附件权。

broker固定可信当前主体/env/purpose/refs，只读检索、详情讨论、公开资料话题趋势、相关推荐及正式发布帮助。原工程7工具/每请求8次/每次20结果有界，无任意DB/Storage/service_role/网络或社交管理写；readOnlyHint不能替强制授权，恶意内容不改工具边界。

社区事实须真实相关可点来源及作者时间，区分无证据/无结果/失败/失权/失效，帮助绑当前document release撤下同传递失效。默认大陆推理日志存储分包且不训练，真实条款获批/配置/健康才调用，不暗换跨境；只传必要正文源不传手机凭据整库。

内测免费，日桶工程初始Asia/Shanghai、60秒超时。并发预留不越额，同成功不多扣，停止/失败实际成本独立未知待对账；额度或预算限流保输入/可知恢复，普通授权搜索可作为行动。AI独立故障不阻社区；来源有权100%硬约束、常规有用≥90%仍暂定。

所有写动作均应用公共CAS/operation/未知结果规则；失败保输入，当前资格变化不复用旧授权。后台动作继续逐操作/资源/env/MFA核验，控件启禁只作提示。

## 完整需求行为

<a id="fr-073"></a>

- **FR-073**：AI 必须提供社区查找、事实问答、帖子／讨论总结、相关推荐、热门发现及社区帮助；支持文字、内部链接及详情主动选取，安全通用问题区分一般知识／社区证据／未知，外链只作文本、不自动抓取；扩展入口仅展示待启用，不默认外联网、附件或语音处理。（AI-01–02；AC-22–23、AC-35）

<a id="fr-074"></a>

- **FR-074**：模型选择必须只含后台真实获批且配置成功模型，展示当前选择与不可用状态；切换继续作者许可及数据政策，未合格或未批准模型不得处理用户数据。（AI-03；AC-22、AC-42）

<a id="fr-075"></a>

- **FR-075**：AI 工具必须只读社区检索、详情／讨论、公开资料／话题／趋势、相关推荐及审核帮助资料；禁止社交写入、账号修改、后台管理和任意数据／网络执行。参数、返回量、上下文及调用次数有边界，内容中的指令不能改变权限、泄密或扩展工具。（AI-04、AI-07；AC-22）

<a id="fr-076"></a>

- **FR-076**：每次 AI 工具调用必须绑定当前用户并检查资源、依赖、作者用途、账号和拉黑，不沿用建会话时快照或高权限凭据跨用户读取。（AI-05；AC-06、AC-22–25）

<a id="fr-077"></a>

- **FR-077**：每项社区事实结论必须有真实相关可点击来源及必要作者／时间／内容标识，点击重新授权；无证据、无结果、工具失败、失权、来源失效分别反馈，不编造帖子、投票、规则或引用。（AI-06；AC-22）

<a id="fr-078"></a>

- **FR-078**：广泛问答／热门／自动推荐必须仅使用符合全部用途、过滤与当前资格的有效公开内容。受限帖不批量进入公共总结，只能由有权用户主动选中、作者用途允许并完成必要处理告知；仅自己帖／草稿须本人主动选择并确认。私信、证据、管理员记录、待审／限制／已删除内容和旧版无通用 AI 选取入口。已识别内部引用执行来源规则，无法识别粘贴不授予额外源／附件访问。（AI-08、PRD 第 12.2 节；AC-23）

<a id="fr-079"></a>

- **FR-079**：AI 必须仅传当前请求必要正文与来源，不发送手机号、凭据、无关资料或整库。推理、日志、存储及分包处理默认限中国大陆、未经单独批准不跨境；服务商明确不训练并可核验地域、保留、删除与分包条款，仅已批准且合格服务可用，配置和故障不能暗换处理方。（AI-09；AC-42）

<a id="fr-080"></a>

- **FR-080**：账户必须分别控制 AI 检索、总结、推荐，逐帖只能进一步关闭，有效许可为账户与逐帖交集；公开内容按已明确告知规则默认参与，不等同同意任意第三方处理。（AI-10；AC-24）

<a id="fr-081"></a>

- **FR-081**：必须按实际用途判定许可：检索用于查找／返回链接，总结用于生成来源摘要或事实回答，推荐用于选择／排序相关内容。混合流程满足全部涉及许可；只允许检索时不能生成摘要，推荐候选也不可包含禁推荐内容，允许阅读不等于允许 AI。（AI-11；AC-23–24）

<a id="fr-082"></a>

- **FR-082**：关闭用途必须立即停止后续该用途调用及受影响历史、上下文、索引／缓存使用，普通关键词搜索不受该 AI 设置替代；重开重新确认当前有效性，不复活已删或受限内容。（AI-12；AC-24–25）

<a id="fr-083"></a>

- **FR-083**：回答必须保持直接及经旧回答引入来源的依赖关联；删除、失权、拉黑、限制或作者撤回用途后，相关原文、摘要、引用和实质依赖回答退出展示及后续上下文。（AI-13；AC-25）

<a id="fr-084"></a>

- **FR-084**：来源可可靠区分时可重新生成不依赖撤回来源的答案，否则整条隐藏并标不可用；不能只删链接留答案或由续问重述。历史、标题、复制、重试、继续与跳转必须重验，离线不展示未核验受限依赖，系统外副本不保证收回。（AI-14–15；AC-25）

<a id="fr-085"></a>

- **FR-085**：AI 必须支持新建、本人历史、打开旧会话、自动短标题及改名、删除、停止、复制合法答案、重试和基本反馈；历史／标题仅本人可读且标题不保留失权摘要，删除立即退出正常 UI／检索／上下文。（AI-16；AC-25–26）

<a id="fr-086"></a>

- **FR-086**：AI 必须区分提交、检索、生成、完成、停止、失败和结果待确认；超时／断网保留输入及合法历史，不把截断答案标完成，重试关联原请求，不重复气泡／额度／费用账目，已收费未知时待对账。（AI-17；AC-26）

<a id="fr-087"></a>

- **FR-087**：内测必须免费，初始每日每用户最多 20 个成功完成请求，输入最多 8,000 Token 含检索上下文、输出 2,000 Token；按配置时区重置，用户组／功能限额受控。明确失败且未完成不重复扣，未知需核实，停止可能已产生真实成本不得抹除，并发不越额。（AI-18；AC-26）

<a id="fr-088"></a>

- **FR-088**：必须提供单用户／单次／全局预算、频率、告警及高成本保护，限额或限流告知原因及可知恢复时间并保留输入；全局保护可暂停新 AI，普通有权搜索可作为行动入口，不放宽数据资格或暗转第三方。（AI-19；AC-26、AC-42）

<a id="fr-089"></a>

- **FR-089**：AI 独立故障必须不阻断正常社区浏览、发布、互动、私信；运维仅管理获授权合格服务、工具及成本策略，记录错误、延迟、用量、实际／待对账费用，工具不越只读，原文访问须独立授权审计。（AI-20；AC-26、AC-30、AC-34、AC-42）

## US8旅程验收

1. **Given** 用户提出社区事实问题，**When** AI 回答，**Then** 结论有真实、相关、当前有权来源；无证据、失败、失权和失效分别反馈，恶意内容不能改变授权或触发写操作。
2. **Given** 受限帖子或本人私人草稿，**When** 未主动选择，**Then** 不自动进入广泛社区问答或上下文；主动选择仍须当前资格、作者用途及必要处理告知／确认。
3. **Given** 账户禁止某用途或逐帖进一步限制，**When** 检索、总结、推荐或混合流程运行，**Then** 执行实际涉及用途的全部许可；禁止总结不能以检索名义生成摘要，普通关键词搜索独立。
4. **Given** 来源撤权、删除或撤回用途，**When** 打开历史、标题、复制、重试、续问或跳来源，**Then** 受影响输出及其后续依赖不显示／不进上下文，无法可靠划分时整条隐藏。
5. **Given** 额度边界、并发、超时、停止或结果未知，**When** 提交／重试，**Then** 输入可恢复，成功额度不重复扣，费用不确定可对账；不存在无意义片段冒充有效回答。
6. **Given** 无获批且符合大陆处理与不训练政策的可用模型，**When** 请求 AI，**Then** 明确不可用并保留输入，不暗换第三方或跨境；普通社区功能不因独立 AI 故障阻断。
