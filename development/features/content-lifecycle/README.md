# 编辑、可见范围、删除恢复与媒体撤权

对应原旅程US5；完整产品义务保留，文档不表示实现或验收通过。[公共规则](../rules.md)适用于以下所有动作。operationId是控件与共享OpenAPI的业务绑定，尚未登记的名称须协调统一，不代表路由已实现。

## 输入、权限、事务与异常边界

评论依赖原帖，中间评论删仅该节点占位；串依赖head、中间项独立占位保序；repost/quote沿来源链取交集，任一必要来源失效整条连附加文字隐藏；媒体/缩略图/分片/旧版继承全部依赖。管理/恢复/证据入口各自授权不授普通/AI权。

普通公开附件同样不设永久无鉴权旁路，严格撤权不是60秒残余窗口。外部已发字节/截图不可保证收回；已有AD04流截断仅对应70秒观测，非立即EOF承诺。离线不得显示无法核验他人受限资源/依赖回答，退出清受限cache。

删除user/moderation/account分开，dependency_hide不是新删除不重置期限；physical_removed终态无普通恢复，管理员处置仅复核申诉。恢复子项不使无效root/head可读，重建索引/恢复/重新公开都核当前身份审核block媒体及依赖。物理清理和独立证据见data-lifecycle。

所有写动作均应用公共CAS/operation/未知结果规则；失败保输入，当前资格变化不复用旧授权。后台动作继续逐操作/资源/env/MFA核验，控件启禁只作提示。

## 最小必要验证

1. A/B有效关注/C普通/D被block/访客经正文摘要标签缩图quote文字旧版媒体全入口，权限在新输出前变则拒。
2. 编辑待审驳回只最后通过版，审核revision与再编辑竞争不公开后来未审版。
3. 10秒/30天边界、head当次集、独立删处置/缺媒体/子项恢复；旧URL/Range/cache/304/实时/离线不绕权。

日常目标和直接影响回归，正式结论需真实客户端与隔离服务；后置/缺资源消费者保持未验证，编译、mock或截图不替业务通过。

## 完整需求行为

<a id="fr-041"></a>

- **FR-041**：已收到互动的帖子／长帖必须仍可编辑正文、标签、图片替代文本，不替换已发布媒体、不改变原引用关系，投票按其锁定规则。（EDIT-01；AC-14）

<a id="fr-042"></a>

- **FR-042**：必须保存编辑记录并标已编辑，作者可读本人帖历史、获授权审核员可按具体案件读必要历史且审计；普通用户不默认浏览全部旧版，历史仍受当前权限、状态与删除约束。（EDIT-02；AC-14）

<a id="fr-043"></a>

- **FR-043**：编辑必须重新完成必要审核，新版本待审／驳回期间读者见最后通过版本，作者管理见真实新版本状态；通过后只切换被审核版本，普通帖、评论、引用文字及允许编辑投票说明一致，独立限制仍可隐藏整条。（EDIT-03；AC-37）

<a id="fr-044"></a>

- **FR-044**：必须支持公开、仅关注者、仅自己三种范围。每次读取及展示检查当前身份、资源、账号／审核、拉黑、范围与依赖；互动再叠加登录、处罚、回复范围或接收设置，前端入口不充当授权。（VIS-01；AC-06、AC-12、AC-15）

<a id="fr-045"></a>

- **FR-045**：所有信息流、搜索、AI、分享、通知、媒体、版本及受控缓存输出必须执行相同当前边界，正文、摘要、缩略图、标签、引用文字、结果卡及实时输出均受保护。（VIS-02；AC-06、AC-15、AC-25、AC-27、AC-31）

<a id="fr-046"></a>

- **FR-046**：转发／引用必须仅有权阅读且允许互动者可创建，有效范围取自身与来源当前授权交集；再引用沿链检查，任一必要来源不可用即整条含附加文字停止展示，仅留合法最小占位。（VIS-03；AC-08、AC-15–16）

<a id="fr-047"></a>

- **FR-047**：关联读取必须区分评论依赖原帖、中间节点占位、串依赖首帖、引用链交集和媒体继承；管理／恢复／证据入口各自授权，不由管理资格授予普通浏览或 AI 资格。（VIS-01–03、PRD 第 9.2 节；AC-10、AC-13–15、AC-23）

<a id="fr-048"></a>

- **FR-048**：主动删除必须立即停止正常内容及附件访问，初始 10 秒撤销提示、删除后 30 天最近删除恢复；恢复先查当前身份、审核、拉黑和依赖，不绕过处置。（DEL-01；AC-15、AC-32）

<a id="fr-049"></a>

- **FR-049**：恢复首帖必须带回当次连带隐藏且仍有效条目，独立删除／限制条目不复活；恢复子项不使无效原帖／首帖可读，独立恢复期限从真实删除时间算，不因依赖隐藏重置。（DEL-02；AC-10、AC-15）

<a id="fr-050"></a>

- **FR-050**：管理员违规删除／依法限制必须走复核或申诉，不能普通最近删除恢复；到期永久清理不提供普通恢复，独立证据不接回公共业务。（DEL-03；AC-15、AC-29、AC-32）

<a id="fr-051"></a>

- **FR-051**：必须分开立即业务拒绝与物理清理，恢复期保护唯一必要副本，到期清理对象、关联及索引；普通媒体也须新访问撤权即拒绝，清理未完成不是继续访问许可。（DEL-04；AC-31–32）

<a id="fr-052"></a>

- **FR-052**：恢复、重新公开或重建索引必须重新确认所有当前依赖与资格，仅恢复仍有效状态；不可恢复外部另存副本须向用户说明，不保证全网同步撤回。（VIS-01–03、DEL-01–04；AC-15、AC-27、AC-32）

<a id="fr-108"></a>

- **FR-108**：媒体、缩略图、GIF、视频分片、预览及下载必须继承所属资源和关联依赖的当前资格；外部地址和高权限凭据不得成为绕过授权入口，客户端或公开产物不含秘密。（MEDIA-01；AC-31、AC-50）

<a id="fr-109"></a>

- **FR-109**：所有普通及敏感媒体在系统可控的后续新读取上必须撤权即拒绝，含旧地址和缓存命中；不等待签名、缓存或会话过期，暂定 60 秒签名不是残余许可，真实失权访问属于缺陷。（MEDIA-02；AC-31）

<a id="fr-110"></a>

- **FR-110**：离线必须不显示无法重新确认的他人受限帖子、媒体及依赖回答；本人未发布本地草稿可按草稿规则恢复，退出清理应用受限缓存／地址／会话关联。（MEDIA-03；AC-17、AC-25、AC-31）

<a id="fr-111"></a>

- **FR-111**：永久删除必须同步处理实际对象、派生文件、关联、索引及应用管理缓存；单人撤权不删其他合法用户共同对象，恢复／证据保留不授予普通访问，系统外另存不保证收回。（MEDIA-04；AC-31–32）

## US5旅程验收

1. **Given** 作者编辑已公开内容，**When** 新版本待审核或被驳回，**Then** 读者继续看最后通过版本，作者可看新版本状态；通过决定只发布其对应版本，独立违规限制仍可隐藏整条。
2. **Given** 作者收紧权限、移除关注者或发生拉黑，**When** 失权用户再次访问任一关联入口、旧地址或系统缓存，**Then** 新访问立即拒绝，正文、摘要、缩略图、媒体及失效引用的附加文字均不输出。
3. **Given** 用户主动删除内容，**When** 在 10 秒提示或删除后 30 天窗口内恢复，**Then** 经当前权限、审核和依赖校验恢复；恢复期内唯一必要副本不被提前清理，管理员处置不能普通恢复。
4. **Given** 首帖删除连带隐藏整串，**When** 恢复首帖，**Then** 带回当次连带隐藏且仍有效的条目，独立删除／限制条目不复活；中间项保留顺序占位，依赖隐藏不重置独立删除期限。
5. **Given** 设备离线或内容已被外部另存，**When** 请求受限内容，**Then** 无法重新核验的他人受限内容及依赖回答不离线展示；产品明确外部副本不能保证收回。
