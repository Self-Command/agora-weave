# 评论、深层回复与单选投票

对应原旅程US4；完整产品义务保留，文档不表示实现或验收通过。[公共规则](../rules.md)适用于以下所有动作。operationId是控件与共享OpenAPI的业务绑定，尚未登记的名称须协调统一，不代表路由已实现。

## 输入、权限、事务与异常边界

投票2–4选项、5分钟–7天，选项100字符工程初值，问题受所属正文限额。截止用权威时间，job未跑也拒票。结束写参与者去重站内事件，推送另设置，统计经详情/搜索/AI/通知/分享/API同权，原帖失效同步受限。

评论编辑同最后通过revision策略，普通用户无全部历史。中间占位不从预览/附件/旧版重述删除正文；热门真实互动衰减不放授权。无评论收藏或未经确认评论转发引用，GIF行为需实际双端验证。

所有写动作均应用公共CAS/operation/未知结果规则；失败保输入，当前资格变化不复用旧授权。后台动作继续逐操作/资源/env/MFA核验，控件启禁只作提示。

## 最小必要验证

1. 首票与三字段编辑/截止/结束/重复票并发一合法锁状态，原截止保留，更正不改票。
2. 未投作者/用户/访客所有入口零进行统计，结束有权可读、通知一次。
3. 三层以上保reply_to；删中间/原帖分别效果；关闭/改范围新嵌套即生效旧合法回复保留。

## 完整需求行为

<a id="fr-028"></a>

- **FR-028**：投票必须单选、每用户仅一次成功、不改票、不公开投票者名单，初始 2–4 选项、5 分钟至 7 天；当前有效策略受统一配置与既有票保护约束。（POL-01；AC-11–12）

<a id="fr-029"></a>

- **FR-029**：首票前必须可修改问题、选项及原截止时间，首票成功后三项全部锁定；说明编辑不得改变语义并显示已编辑，首票与编辑并发只形成一致合法结果。（POL-02、POL-06；AC-11）

<a id="fr-030"></a>

- **FR-030**：投票更正必须为独立作者／时间／内容记录，与原投票同权，不能覆盖原语义或票；结果和讨论中可访问。（POL-03；AC-11）

<a id="fr-031"></a>

- **FR-031**：进行中统计必须仅已投且当前可读登录者可见，包括作者无未投例外；结束后所有有权者含公开投票访客可见，不从搜索、AI、通知或其他入口提前暴露。（POL-04；AC-12）

<a id="fr-032"></a>

- **FR-032**：到期或作者提前结束必须停止新票；提前结束记录实际时间及标准原因／简短说明，保留原截止、不重开、不用编辑变相延长缩短，截止判断以权威时间为准。（POL-05–06；AC-11–12）

<a id="fr-033"></a>

- **FR-033**：投票并发与有效计数必须一致，重复票至多一次；结束向参与者发合法站内通知，推送服从设置，原帖失效／失权后统计及通知同步受限。（POL-06–07；AC-11–12）

<a id="fr-034"></a>

- **FR-034**：评论必须支持文本、Emoji、回复、点赞／取消、编辑、删除、举报及至多 4 图或 1 GIF；不混附，不支持视频、投票，大小按参数表，不生成独立链接卡。（CMT-01、CMT-07；AC-13）

<a id="fr-035"></a>

- **FR-035**：评论必须按主评论、二级、三级展示，更深回复归所属线程并保留父节点与被回复对象，不无限缩进或丢上下文。（CMT-02；AC-13）

<a id="fr-036"></a>

- **FR-036**：中间评论删除／限制必须为适当无正文占位，不级联删除他人合法子回复，不通过预览、附件或旧版本重述不可用文本。（CMT-03；AC-13、AC-15）

<a id="fr-037"></a>

- **FR-037**：一级评论必须默认最新倒序、可切热门，线程回复按时间正序；热门按有效互动及时间衰减，排序不暴露失权、屏蔽、拉黑或删除内容。（CMT-04；AC-13）

<a id="fr-038"></a>

- **FR-038**：作者必须可选择所有有权读者、作者关注账号、原帖提及账号或关闭评论；新主评论及嵌套回复按阅读范围与回复范围交集，关闭保留合法旧评论，重开立即按当前规则。（CMT-05–06；AC-13）

<a id="fr-039"></a>

- **FR-039**：本人评论必须可编辑正文和附件替代文本，不能替换已发布媒体；保留必要治理历史并显示已编辑，普通用户不默认浏览完整旧版，编辑审核遵循 FR-043。（CMT-07；AC-13–14、AC-37）

<a id="fr-040"></a>

- **FR-040**：首版不得提供独立评论收藏或未经确认的评论转发／引用；原帖删除时整棵讨论退出正常访问，评论链接、检索和附件不得绕过。（CMT-08；AC-13、AC-15）

## US4旅程验收

1. **Given** 投票尚无成功票，**When** 首票与修改问题、选项、截止时间竞争，**Then** 只形成一致结果；首票写入后三项锁定，不改票，每用户至多一票。
2. **Given** 用户未投票或为访客，**When** 查看进行中投票，**Then** 任何入口都不展示统计；结束后有权者可见，作者未投票无前台例外。
3. **Given** 作者提前结束，**When** 执行操作，**Then** 记录实际结束时间及原因，保留原截止时间，停止新票，不重开；独立更正不覆盖投票语义或旧票。
4. **Given** 中间评论被删除，**When** 读取线程或更深回复，**Then** 该节点为无正文占位，其他合法子回复及对象关系保留，不无限缩进。
5. **Given** 作者关闭评论或改变回复范围，**When** 创建主评论或嵌套回复，**Then** 按当前阅读与回复范围交集检查；既有合法评论不清空，编辑不替换已发布媒体。
