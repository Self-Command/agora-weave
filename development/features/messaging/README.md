对应原旅程US7；完整产品义务保留，文档不表示实现或验收通过。[公共规则](../rules.md)适用于以下所有动作。operationId是控件与共享OpenAPI的业务绑定，尚未登记的名称须协调统一，不代表路由已实现。

## 输入、权限、事务与异常边界

无向pair(lower_account_id,upper_account_id)唯一，sender/recipient仅动作权，A→B/B→A不建两pending。创建/接受/过期/直接发送统一pair锁顺序，同锁按权威时钟先终结过期再判创建；竞争409或同operation复用，不覆盖追加自动接受。

旧请求后取得直接资格的新消息进唯一正常会话，旧initial独立原期限直到显式合法接受。拒删取消过期不终止合法会话；关全部旧请求可看删举报不可accept，重开只有效者可办，block终结不复活。

逐message_access与conversation_member分开，旧URL/Range/重连/会话重现/备份不恢复删除方资格，案件证据不授普通读。免打扰不丢持久同步；未读跨端最终一致。无视频/群聊/通话/全员撤回/公开在线；GIF需实际验证。

所有写动作均应用公共CAS/operation/未知结果规则；失败保输入，当前资格变化不复用旧授权。后台动作继续逐操作/资源/env/MFA核验，控件启禁只作提示。

## 完整需求行为

<a id="fr-061"></a>

- **FR-061**：正常会话必须提供文本、Emoji、图片、GIF、链接、会话列表、全部／未读、选人新建、消息时间、收发、未读同步、免打扰、举报与拉黑，不提供群聊、通话或全员撤回。（DM-01；AC-19–21）

<a id="fr-062"></a>

- **FR-062**：接收设置必须初始允许当前有效关注者直接发信、陌生人一条请求，允许关闭陌生人请求、调整接收范围或关闭全部，拉黑始终优先；发送者关注接收者才算资格，待请求／反向关注不算，成功无审批关注可取得资格，不伪造认证范围。（DM-02；AC-19）

<a id="fr-063"></a>

- **FR-063**：合法直接发信或显式接受建立的正常会话必须不因取消关注、关闭陌生人请求或启用审批自动终止；拉黑、关闭全部及适用安全限制拒绝新消息，每次发送检查双方当前资格。（DM-03；AC-20）

<a id="fr-064"></a>

- **FR-064**：找人、发请求、接受必须分别授权，正常会话不授予受限帖子、名单或关注关系，批准关注不自动接受旧私信请求。（DM-04；AC-19、AC-54）

<a id="fr-065"></a>

- **FR-065**：陌生人请求必须每对至多一个待处理，仅一条文本／Emoji、不含链接或附件、不追加／借修改反复提醒；接收者可接受、拒绝、删除、举报、拉黑，发送者可取消。初始创建后 30 天过期，拒绝／删除／自然过期后冷却 30 天、取消后 7 天，发送者统一见结束；过期不能接受、冷却不绕过拉黑，与关注请求独立。（DM-05、PRD 第 11.2 节；AC-19）

<a id="fr-066"></a>

- **FR-066**：接收设置变化必须不自动接受或重置请求；关闭全部后待请求保留原期限且可看／删／举报、不可接受，重开只处理仍有效者，结束／过期／被拉黑阻止的旧请求不复活。（DM-06；AC-19、AC-54）

<a id="fr-067"></a>

- **FR-067**：已有请求后取得直接资格的新消息必须进入该对唯一正常会话，初始请求独立至显式合法接受才合入，按原消息时间定位；接受／过期／发送竞争有一致终态，不生成第二会话或重复消息。请求箱与会话未读独立：合入沿用各方实际阅读状态、不额外新增提醒，未读消息在正常会话只计一次；旧请求结束／冷却不终止仍合法正常会话。（DM-12；AC-20、AC-54；DM 细化规则）

<a id="fr-068"></a>

- **FR-068**：发送必须区分本地待发、发送中、已保存、设备已送达、已读、失败、结果待确认；断网保留输入，未知先查结果，重试不重复消息或计数，推送接受不证明送达／已读。（DM-07；AC-20）

<a id="fr-069"></a>

- **FR-069**：消息、请求及未读必须持久化，重连补同步、跨设备阅读最终一致，分页与实时不重复；免打扰仅影响提醒，不阻止存储或同步。（DM-08；AC-20）

<a id="fr-070"></a>

- **FR-070**：本人单条删除必须立即隐藏并撤销正常消息／附件访问，不影响对方合法资格、不直接误删共享数据；删除会话仅移除本人列表，合法新消息可使其重现但只读本人仍有权历史，不恢复已删单条、不解除拉黑或重开请求。（DM-09；AC-21）

<a id="fr-071"></a>

- **FR-071**：回执必须默认关闭、双方均开才互显，任一关闭双方不显示而本人未读不变；输入提示可独立关闭，信号短暂、不长期保存，不公开在线或最后活跃。（DM-10；AC-21）

<a id="fr-072"></a>

- **FR-072**：私信附件必须每次新访问检查合法参与者及该条消息资格，单条删除后旧地址、分页、重连和会话重现不能访问；举报只授予案件最小证据资格，不恢复普通访问，后台无任意会话浏览。（DM-11；AC-21、AC-30–32）

## US7旅程验收

1. **Given** 默认接收规则，**When** 有效关注者直接发信或陌生人发请求，**Then** 前者可建正常会话，后者至多一条文本／Emoji 初始请求，不含链接或附件，未接受前不可追加。
2. **Given** 旧请求仍待处理，发送者后来取得直接发信资格，**When** 发送新消息，**Then** 新消息进入唯一正常会话，初始请求独立保留且原期限不变；正常历史不能提前读初始消息。
3. **Given** 正常会话已存在且旧请求有效，**When** 接收者显式接受，**Then** 初始消息按原始时间合入同一聊天，不重复消息、会话、未读或提醒；旧请求结束不终止仍合法会话。
4. **Given** 接收者关闭全部私信，**When** 查看、接受旧请求或发送新消息，**Then** 请求可按原期限查看、删除、举报但不能接受，新消息拒绝；重开不复活已结束／过期／被拉黑阻止的请求。
5. **Given** 本人删除单条消息或会话，**When** 分页、重连、重新出现会话、访问附件或恢复备份，**Then** 单条已撤销资格不恢复，对方合法访问独立保留；会话重现只显示本人仍有权历史。
6. **Given** 重试、跨端阅读或设置回执，**When** 查看状态，**Then** 保存、送达、已读分离；回执默认关且双方均开才互显，任一关闭不影响本人未读，推送接受不当送达或已读。
