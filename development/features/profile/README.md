## 输入、权限、事务与异常边界

所在地非必填，昵称与用户名分开。用户名初始工程格式3–30 ASCII、大小写归一，实际格式保留词从登记配置取。关注审批/帖子范围/私信请求独立，接受之一不授其余权。

mute默认过滤流、普通通知、主动AI推荐/热门/总结，明确显示屏蔽搜索或查已知仍需资源资格。block不承诺跨账号/退出后同自然人绝不见公开内容，不做侵入设备追踪；明细互藏不任意删合法聚合。

video_policy=always/wifi_only/never、preload布尔，初始视频wifi_only静音，preload初值未明确。App保存成功后合法播放器消费本人当前值，失败不假生效。本机主题不加账号同步。分享页绝不读写账号preferences。

所有写动作均应用公共CAS/operation/未知结果规则；失败保输入，当前资格变化不复用旧授权。后台动作继续逐操作/资源/env/MFA核验，控件启禁只作提示。

## 最小必要验证

1. 用户名归一并发、频率/旧名30天两侧，旧分享/提及仍同账号。
2. 审批启闭/接受过期竞争、移粉撤受限媒体搜索AI分享新读、解block不恢复；follow/DM请求期限不混。
3. 实际GET/PATCH未列字段不变，PUT405/Allow、CAS、非法值无半保存、幂等冲突；share-read先拒私人用途。

日常目标和直接影响回归，正式结论需真实客户端与隔离服务；后置/缺资源消费者保持未验证，编译、mock或截图不替业务通过。

## 完整需求行为

<a id="fr-009"></a>

- **FR-009**：主页必须展示和允许本人编辑头像、昵称、唯一用户名、简介、可选背景图，并展示注册时间、当前有效关注／粉丝数及帖子、回复、转发、媒体分类；所在地不作为首版必填资料。（PRF-01；AC-04）

<a id="fr-010"></a>

- **FR-010**：资料与内容必须分别授权；主页不能公开私人收藏、草稿、AI 会话或未获发布资格内容，作者在本人管理入口可查看待审、未通过、限制、已编辑及删除状态。（PRF-02；AC-04、AC-37）

<a id="fr-011"></a>

- **FR-011**：用户名必须独立于昵称并校验当前格式、唯一性及保留词，初始 30 天最多改一次、旧名占用冷却 30 天；稳定链接／提及不随名称抢注转向他人，历史提及显示当前名称。（PRF-03；AC-04）

<a id="fr-012"></a>

- **FR-012**：关注必须默认立即生效；启用审批后新请求仅在批准时计为有效关系，启用保留既有粉丝，关闭不自动批准待请求。（SOC-01–02；AC-05）

<a id="fr-013"></a>

- **FR-013**：关注请求必须可批准、拒绝、删除或由发送者取消，同对账号至多一个待请求；创建后 30 天过期，拒绝／删除后冷却 30 天、取消／自然过期后 7 天；发送者只见统一结束，反骚扰限制不得由重装、多端或重复点击绕过。（SOC-03–04；AC-05）

<a id="fr-014"></a>

- **FR-014**：取消关注或移除粉丝必须立即撤回由该关系授予的内容资格，不改变公开内容；重新关注按当前审批、冷却及拉黑条件，解除拉黑不自动恢复关注。（SOC-05–06；AC-06–07）

<a id="fr-015"></a>

- **FR-015**：访客必须只能读取允许公开的关系数量，不能打开具体名单；登录者访问公开账号名单仍检查当前资格，审批账号名单仅本人及获准关注者可读，逐条过滤账号状态与拉黑。（SOC-07；AC-04–07）

<a id="fr-016"></a>

- **FR-016**：关注审批、帖子可见性与私信请求必须独立；批准关注不自动接受私信，接受私信不授予关注、名单或受限帖子权利。（SOC-08；AC-05、AC-19、AC-54）

<a id="fr-017"></a>

- **FR-017**：必须分别提供账号／关键词／话题屏蔽、拉黑、会话免打扰及移除粉丝。屏蔽过滤默认信息流、普通通知及主动 AI 推荐／热门／总结，主动显示搜索或明确查找已知内容仍须有权；不通知被屏蔽方。拉黑解除双向关注、互藏内容与具体互动并拒绝新互动／联系，既有合法私信历史只读，合法历史及聚合数不任意删，不以侵入性追踪承诺同一自然人绝对看不到公开内容。（SOC-09–10、PRD 第 5.3 节；AC-07）

## US2旅程验收

1. **Given** 用户修改唯一用户名，**When** 打开旧分享链接或历史提及，**Then** 仍指向同一账号并显示当前名称；30 天修改频率和旧名占用冷却生效，主页不暴露收藏、草稿或 AI 历史。
2. **Given** 用户启用审批且已有粉丝、待请求，**When** 启用或关闭审批，**Then** 既有粉丝保留，待请求不自动批准、不计入有效关注数；同对账号至多一个待请求。
3. **Given** 关注请求拒绝、删除、主动取消或自然过期，**When** 再次申请，**Then** 分别执行 30／7 天冷却及当前拉黑规则，与私信请求独立；发送者只见统一结束状态。
4. **Given** 用户屏蔽或拉黑另一个账号，**When** 查看信息流、搜索、通知、名单或发起互动，**Then** 屏蔽按偏好过滤，拉黑解除双向关注并拒绝新互动；合法历史聚合数不任意删除，解除拉黑不自动恢复关注。
5. **Given** 访客或普通登录者访问关系名单，**When** 打开公开或审批账号的名单，**Then** 访客仅见允许公开的数量，具体名单按当前登录与审批资格展示。
