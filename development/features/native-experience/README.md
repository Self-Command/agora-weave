## 输入、权限、事务与异常边界

Expo/RN/Expo UI原生顶栏安全区/系统栏键盘IME滚动弹层，复用原型页状态主题及必要原生适配；后台完整Kiranism。App/后台缺失页面按文档直接开发后由用户验收，不逐页等待预批；分享仍按原范围后置。

简中/系统字缩放较大字号/长昵称长文三层回复窄屏可达，VoiceOver/TalkBack标签角色状态焦点顺序、纯图标名、44pt/48dp触区/正文4.5:1，错误不只色、alt/减少动效。语义树/audit不冒称真的辅助技术执行，平台限制真实记。本机主题不加账号同步。

GIF仅可视区自动，省流量/减少动效静态预览给可读屏显式播放，离屏失焦后台暂停释放或量化降耗；Wi-Fi转蜂窝不自动启动/预取未选媒体，关preload取消在途推测请求，主动缓冲独立记录。GET/Range/cache当前gate，退出注销撤权离线反馈真实，GIF首帧不等播放。

逐入口实际义务：发布预览/正文详情、资料主页、流搜索收藏引用、评论GIF、私信GIF、分享各浏览器、获准后台预览、移动后台Host媒体binding；评论DM无视频。保网络类型/Range字节/帧/播放器音量/视区焦点/预取取消释放时间线，截图策略单测不证明。

UI、交互及前端逻辑由用户在人工验收.md反馈；AI不进行日常前端巡检。仅用户报告样式/布局问题后才调用UI角色检查对应页面/状态，平时禁止工作；开发修复后登记待用户复查。完整原生/业务流程在当前首版功能齐备后集中运行；HTML/UI-SPEC/token/page-registry继续保留，不伪造验收通过。

所有写动作均应用公共CAS/operation/未知结果规则；失败保输入，当前资格变化不复用旧授权。后台动作继续逐操作/资源/env/MFA核验，控件启禁只作提示。

## US16旅程验收

1. **Given** 五个移动主入口和头像侧栏，**When** 访问本人资料及管理功能，**Then** 首页／发现／AI／私信／我的可达，设置、草稿、收藏、最近删除在侧栏；菜单保留图标与文字，纯图标有读屏名称。
2. **Given** 无数据、提交中、失败、失权或插件不兼容，**When** 查看页面及操作结果，**Then** 状态真实且有合法行动，不显示假成功、假能力、空白死路或私密拒绝原因。
3. **Given** 大字号、读屏、窄屏、长昵称或键盘，**When** 注册、发布、评论、私信、举报和申诉，**Then** 必要内容及操作可达，焦点和标签正确，错误不只靠颜色。
4. **Given** 历史草稿包含徽章、假系统栏、虚构数据或扩展演示，**When** 实际实现，**Then** 仅沿用有效设计意图，不引入未经确认业务；原生适配差异及各端截图／交互证据可追溯。
