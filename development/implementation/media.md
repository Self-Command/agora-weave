# 媒体播放、偏好与各端消费

这是完整产品的后续实现约束，当前源码并未交付所有播放器、设置与消费入口。类型、大小、上传组合以功能文档及固定API契约为准，不因统一播放器给评论/私信新增视频。上传成功、策略单测或截图不能代真实下载、播放与原生交互。

## 持久偏好与来源

本人App以`GET/PATCH /me/preferences`管理注册字段、`base_version`与`operation_id`。PATCH仅改明确列出的字段，其他已存偏好保持；非法枚举/类型/未注册字段拒绝且不部分提交，CAS错版409保输入，同operation同payload复用、异payload冲突。PUT不注册，应405并声明GET/PATCH；分享audience仍先拒私人路由。

video_policy为always/wifi_only/never，初始wifi_only：always可Wi-Fi/蜂窝自动，wifi_only只Wi-Fi自动，never均本人点击。自动视频初始静音，主动开声/静音有真实控件，新条目不无意继承上一条开声。preload=false停止未主动播放的推测性下载/离屏预取，主动播放缓冲不算推测预加载；此前未明确preload初始布尔值，不自行追加产品默认。

分享匿名与登录都只从获准平台默认和本页操作求播放状态；不得调用完整/部分私人preferences，不从config/effective、SSR高权查询、hydration、缓存、媒体DTO或登录响应派生本人选择。页面可主动播放/暂停/开声/静音/调整本页自动播放和关闭预加载，只改页面状态，不写账号、不声称保存同步。浏览器不能确认网络或拒自动播放时明确点击回退；登录只影响内容读权。

## 播放器与系统状态

视频/GIF组件与网络、可视区、焦点、前后台、省流量和减少动效输入集中复用，常规布局沿已批设计。GIF只在可视且当前系统条件允许时自动动，受限时静态预览+显式播放；移出可视/失焦暂停释放或可测降耗。Wi-Fi转蜂窝时wifi_only不继续自动启动或预取未主动选择媒体，主动缓冲单列说明。

本地设置不能授媒体读权。所有GET/HEAD/Range/缓存命中仍过当前媒体gate，撤权停止后续新读；退出、前台恢复、离线重开不得从磁盘恢复他人旧受限媒体。仅本人未发布本地草稿有合法离线恢复路径。

## 实际入口与验证责任

共享播放器先供发布预览/正文详情，再由主页、流/搜索/收藏、评论/私信各自合法GIF、分享、后台预览和插件host消费。每个入口登记真实组件、播放输入来源与适用行为，不把编辑器接入代表所有入口。后台/插件只用其audience既有合法投影，不因同语义多拿私人偏好。

| 条件 | 必须观察到的行为与证据 |
| --- | --- |
| 新用户/三策略/两网络 | 偏好实际GET/PATCH、实际网络条件与播放器状态；蜂窝未点不默认自动，静音/开声有真实操作 |
| partial/CAS/幂等/PUT | 未列字段保留，非法/错版无半提交，重复一效果，PUT拒绝 |
| 分享账号已存相反策略 | 匿名/登录同默认来源，私人读取与伪config拒，HTML/DTO不泄个人字段，本页操作不改DB |
| 关闭预加载/滚动/主动播放 | gate请求/Range/bytes和任务取消时间线证明无推测下载；主动缓冲另计 |
| 网络切换/前后台/失焦 | 原生状态变化、暂停/释放或量化降耗；不能把注入网络值称无线电实测 |
| GIF省流量/减少动效/重入 | 实际系统设置、帧变化与请求，静态预览和可访问播放入口 |
| 撤权/退出/断网 | gate真实拒绝及停止后续输出，已交付bytes单列，界面给真实不可用 |

主触区iOS44pt/Android48dp、动态字体/读屏语义、焦点、键盘和安全区均需真实端证据。原生功能在Actions最低/当前OS验证；布局样式本地固定独立UI角色单主题整页复检，不用图像推断网络/音量/播放或当前权限。完整范围见[模拟器契约](../contracts/simulator-validation.md)和[HTTP语义](../contracts/http-api.md)。
