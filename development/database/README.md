# 数据库入口

- [实际字段字典](schema.md)：从仓库SQL提取的当前表、字段、约束与索引，不是第二套建表来源。
- [事务与迁移](migrations.md)：应用依赖、当前资格、原子性、并发、清理和恢复边界。
- [完整领域模型](domain-model.md)：保留未来产品实体与状态约束，未落SQL的设计不能冒称已应用。

真实schema由 `supabase/migrations/*.sql` 及目标库已应用摘要决定。已应用SQL不改写；新迁移编号由主控单写。
共享DB串行，不自动重置、seed或新建重复dev组。授权和业务不变量在服务端/事务内落实，字典存在不代表业务已实现。
