# UI设计来源、批准与实现

设计源保留在[UI-SPEC](../../docs/design/UI-SPEC.md)、[design-tokens](../../docs/design/design-tokens.json)、[page-registry](../../docs/design/page-registry.json)及[统一HTML原型](../../docs/design/prototype/index.html)，原文件不重画、不复制成另一份原型。本文解释当前授权边界；精确页面/状态/版本快照见[pages](pages.md)。历史UI-SPEC中云端视觉矩阵和旧生成器语句已被现行用户决定取代：视觉在本地单主题独立复检，Actions保真实功能/原生/构建，不恢复旧流程。

## 当前人工验收方式

用户2026-10-18最新决定优先三端快速开发：App、后台直接按现有产品规则与原型实现缺失页面，实际客户端由用户人工验收，不再逐页等待开发前原型批准，不安排独立UI复检。反馈固定在仓库根`人工验收.md`，开发不等待反馈；用户报告后修复并登记待复查。已有原型与批准记录保持原样，新增页面记待用户验收，不补造历史批准。分享Web仍属后置，原页面批准边界保留。

## 页面与批准（历史来源；App/后台执行以上最新决定）

App/分享新增整页或设计变化须先在统一HTML入口补对应页面及状态，由用户明确批准该具体版本再实现生产UI。基础组件批准只覆盖组件，v6风格认可不自动授所有新整页；未登记的页面/状态不能从类似页面批准推断。已批设计直接复用不重画；设计未变的实现修复沿匹配批准继续。

开发者实际打开给定page/scene/theme查看画面和必要交互，再阅读对应JS/CSS、token和现有实现；不能把旧生产画面、画板外壳、假系统栏、演示计数/权限当产品规则。本文静态整理未启动浏览器，不宣称完成开发前实际查看或真实UI复检。

后台直接以[Kiranism固定完整官方快照](https://github.com/Kiranism/next-shadcn-dashboard-starter/tree/7705dfc0d13889e45c26a55ad5908da6a7a9a605)为设计基准，无需另画同款HTML。保留完整布局/导航/主题/表格/表单组件后接真实业务；模板政策批准不表示后台业务或实现截图已验收，示例身份/Clerk不能作产品权限。

## 组件与原生适配

App固定Expo/RN/Expo UI，现有免费Uniwind/Tailwind语义className映射`apps/mobile/global.css`和`packages/design/src/tokens.ts`（以当前文件实际位置为准）；必要modifier/props/动态style保留，不把HTML改为WebView产品。后台沿官方Tailwind/shadcn语义。主题本机跟随系统/浅/深，不新增账号同步。

同页、同状态、同主题、正常字体1.0对照布局/信息层级/文案语义/颜色/组件/操作。系统字体、真实安全区、键盘、触控、无障碍可必要适配；明显错页/缺内容/遮挡/设计偏离与功能问题须修，细微渲染差异记录建议，不独立阻塞。改变设计意图或实质差异无法判断交用户决定。

支持动态字体、对比、读屏语义、焦点和安全区；主触区iOS44pt/Android48dp、必要正文对比4.5:1为既有目标。加载/空/失败/unknown/失权/删除/停用/不兼容均反馈真实状态。大字/窄屏/键盘/长文按风险专项，结束恢复正常缩放；不以隐藏系统栏或减小全局字体消差。

## 历史验证分工（已被当前人工验收方式取代）

业务单元/API/集成检验规则、权限、并发与数据；组件检验输入/点击实际触发参数；原生自动化检验真实输入、导航、反馈和生命周期。固定独立UI角色`gpt-5.6-luna/xhigh`只检查稳定集成版本的布局/颜色/遮挡/可读性，单主题多图拼图批量对照、保整页原图，不检查功能交互、不重复dark。

开始前确认源码/运行版本、明确可达入口、设备与采集页面状态，期间不覆盖共享运行区或Fast Refresh。集中列差异后修复，定向复测受影响项；纯文档/未变页面不重开整批。设计批准与首次实际产品基准分开，AI/CI/可运行/沉默不能代人类同意；截图不能代未执行的交互。分享当前仍无整页批准，框架入口不算交付。
