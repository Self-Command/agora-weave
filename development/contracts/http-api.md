# HTTP业务语义与安全约束 v1

方法、路径、字段、必填性、枚举和响应结构以[App](app-api.yaml)、[后台BFF](management-api.yaml)、[核心管理](core-admin-api.yaml)三份OpenAPI 3.0.3共同子集为唯一权威。本文补充跨请求状态、权限、事务和失败语义，不另定义DTO。OpenAPI的`x-implementation`区分implemented/planned；本文件保留完整产品的后续责任，不代表所有接口已可用。结构不一致修正规范与消费者，不能让实现和测试共同漂移。

## 共同行为

- 移动Bearer、后台和分享安全HttpOnly cookie；服务端验证签名、issuer/audience/expiry和当前session/account。客户端channel、role、account、client-release、native capability和config版本不授权，也不能冻结当前撤权。
- 写命令按当前主体/环境/动作/operation_id及payload hash幂等；精确重试只复用当前有权结果，异payload冲突。CAS失败保留输入，不盲覆盖；unknown先查原结果，不自动重发外部效果。
- 保存、审核、公开、供应商接受、送达、已读与物理清理分别反馈，不用202/已受理表示公开或成功完成。游标只定位查询/主体/范围版本，不授权限；聚合与明细分别核资格，过滤名单长度不冒充全量count。
- 无效会话401，动作拒绝403，目标无权/不可用统一404或安全占位；409表达CAS/幂等竞争，422表达格式/上限，429限流，503真实依赖不可用。错误不暴露OTP/token/供应商原始消息/私人原因；可恢复输入、成功上传和原operation继续保留。
- 所有读取先当前授权后合法字段投影；管理/恢复/旧版/证据为独立action，不自动赋普通阅读或AI用途。正文归一换行后按共同Unicode grapheme计数，不自动trim，媒体MB为十进制；结构和精确限制由固定契约/配置承载。

## 账号与会话

公有challenge必须绑定真实入口、受控网关/IP、环境keyed摘要与具体目的，未知字段拒绝。新注册当前邀请、主动年龄声明、正式条款集合和本人明确同意原子准入，Auth主体或手机号verified不自动成为社区账号/管理员；已有账号登录不新增重新同意规则。条款/摘要在提交时再核，更新或缺失保输入并给真实状态。

短信只有供应商明确接受才算发送成功；Auth验证使用官方接口，正确码准入失败不遗留假成功，错误尝试和历史限流继续保留。发送或验证unknown保留operation只查原状态，不重复发送、验证或创建session。短期加密回执最多5分钟且不超过access token期限，重读仍核当前账号/会话；撤权后不能重新返回旧令牌。OTP、refresh和正文不进公开日志。

会话列表只含本人必要设备信息；撤单设备、退出、换号和注销均落实服务端当前资格与耐久拒绝。换号真实验证旧/新身份或受控恢复、24小时敏感保护及其他session撤销；注销立即停访问，分类清理独立。刷新不得复活已撤/已注销会话。分享login/register/change-phone各自受audience与目的边界限制，不能借App路径开放分享注册。

恢复申请只表示受理/核验中/补证/拒绝/批准待执行/实际结果，不凭公开答案或受理状态恢复身份；可信/人工/MFA应急分别核最小证据和执行资格。DEC-001只执行已批准的具体敏感动作清单，保护期不扩成任意禁操作。

## 资料、关系与偏好

资料公开投影与本人管理、关系明细分开；稳定account ID不因可转移username变化，归一用户名唯一与改名/旧名保留规则在事务中核。资料/内容列表不混草稿、收藏或AI历史，访客不获关系明细，审批账号的名单按当前本人/有效关注资格。

关注待请求不涨有效计数；接受/取消/拒绝/删除/到期/屏蔽均单终态，发送者只见统一ended，不泄私人原因。当前拉黑任一方向阻断双向关系及新联系，解除不恢复关注/请求；mute与拉黑/会话静音分开，不授读权。改审批开关不自动接受旧请求。

本人preferences固定GET/PATCH：PATCH只改明确注册字段、未列字段保留；非法枚举/类型/未注册字段拒绝且不半提交，CAS冲突保输入，精确operation重试一效果。PUT不注册，应405并声明GET/PATCH；share-read仍先按用途拒私人路由。账号播放选择/通知/回执/AI用途等只给合法本人App消费者；平台默认不覆盖已存个人选择。

作者收录账号策略与post/thread逐目标策略是本人受控事实，独立于读权和AI用途。目标allow不能越账号false、资源非公开、治理/删除或实际展示依赖。变更主库原子提交/升epoch/outbox，关闭立即noindex，不能等异步投影；旧作业不能复活。具体播放消费见[media](../implementation/media.md)。

## 内容、媒体、讨论与发现

上传在私有暂存，分块失败保成功部分和正文、可合法复用附件；complete不等正式公开，不给源站可读签名。真实格式/编码/大小/时长、归属、审核和绑定都核，不因客户端扩展名或hash自报跳过。孤立清理不能误删有效草稿/已绑资源。

草稿本人私有，CAS冲突由本人选版本；访客本机草稿导入须显式选择，不自动进入公共搜索或AI。发布操作保存真实operation/review状态，未知先查询，失败不清正文。允许的帖子类型和媒体组合严格按功能文档，不新增评论收藏/转发引用、多作者续串等未批准业务。

编辑生成新revision并待审，读取保最后通过版；审核只作用具体revision，不能批准后来未审版。媒体/引用关系不可借正文编辑替换。串同作者/统一范围，首发/续写批次全部媒体和审核就绪后原子公开，不公开半串；旧串不因续写等待整体隐藏。首帖无效整串占位，中间删除保序，恢复只恢复仍合法的当次影响集。

当前阅读、可见性、回复scope、拉黑/治理、原帖/引用/串等依赖取交集；收紧即时拒后续新访问，放宽整串须准确预览。评论保真实parent/reply-to，显示至三层，更深关系不丢；删中间正文占位，合法子回复保留，关闭评论不删历史。quote链任一源失效整条含附加文字隐藏，不能复制成永久独立正文。

首票与编辑/结束锁同一poll：首票后问题、选项、原截止锁定，一人一票不改；服务端时间到截止即拒，不等job。提前结束保原截止不可重开，更正独立记录。投票中仅已投且有权者看统计，结束后当前有权者可看，无投票者名单公开API。

点赞/转发去重，合法聚合和可见互动名单分别计算；收藏本人私密，无公开count/身份/索引，来源失效占位可移除。推荐/关注/最新、搜索/联想/count/话题/趋势先主库资格过滤再排序分页，索引不授权；真实低数据提示，运营精选有标签，不伪造热度。私人搜索历史只本人读取/清除。

媒体GET/HEAD/Range/派生/条件请求/缓存命中全部当前核，no-store、不跳源站，失权不能304。客户端target引用不证明合法绑定，分享只限分享目标媒体。播放/预取不增加读权，离线旧受限副本不重新显示；已交付bytes单列，后续受控输出停止。

主动删除真实10秒撤销/30天恢复窗口与当前资格核，管理处置通过独立申诉，不走普通恢复。最近删除列表不授普通内容读取；依赖隐藏不重算独立期限，物理阶段不能从UI隐藏推断。完整分类保留见[模型](../database/domain-model.md)。

## 私信、通知与可靠效果

发送资格逐次核当前关系/私信策略/处罚/拉黑。请求使用规范化无向account pair唯一pending，A→B与B→A并发也最多一请求、一initial及对应通知效果；其他竞争不替换、不追加、不自动接受原请求，不能泄无权请求详情。同operation只复用结果。

创建、接受、到期与直接发送采用一致pair锁顺序，服务端时间判截止/冷却；过期在同锁内转终态，不靠job或动态时间唯一约束。当前合法直接消息可进入唯一正常会话，但旧initial仍在request域，不进入正常分页，直到显式合法accept再核时间/拉黑/关闭全部/处罚。

接受沿用原initial ID和保存时间，阅读/未读迁移只一次，不新增提醒。逐参与者message_access独立：删单条立即撤本人的消息/附件资格，不误删对方；删会话只改列表，新消息可重现列表但不能复活已撤单条。没有全员撤回功能。

saved、provider accepted、device delivered、actual read分别记录，双方回执开才互显；typing短暂有界、当前双方配置/发送资格，不长期存在线状态。通知按真实互动去重/聚合，失权摘要/目标退出；安全必要通知不被业务开关停用。推送默认通用提醒，受限/私信/证据/验证码正文不外发，provider接受不冒充设备送达或阅读。

## AI用户命令与只读工具

用户可确定性创建/改名/删会话、发送、停止/重试、复制和反馈；这些服务端写命令不赋模型写工具。模型真实availability必须来自合格服务状态，缺服务/预算保输入返回不可用，不能暗换供应商/跨境或mock回答。

每次发送核当前所需处理告知、用途和显式选源；公共广泛检索只合法公开候选，受限主动选择仍要读权及作者用途。self/草稿按原规定明确确认；私信/证据/待审/旧版无通用选取工具。识别出的内部引用不能改称粘贴绕过，无法识别来源的粘贴告知处理而不自动扩展附件读取。

答案、标题、流、历史、复制和续问重核完整直接/传递来源；失效不能可靠拆则整条withdrawn。heartbeat/截断不算成功完成；停止与费用未知独立处理，重试关联原request、unknown先对账，不重复成功次数或供应商费用。完整额度与MCP限制见[AI工具](ai-tools.md)。

## 治理、后台与配置

后台只返回当前角色/action/resource/environment的最小业务投影，无任意私信/草稿/AI原文入口。五角色名称本身不授权限；案件证据须专门最小grant、敏感MFA/原因及访问审计。举报数量不自动认定，反馈不泄举报人。处置按类型/作用范围，撤销只恢复该处置仍合法的影响；原处置人不能独自复核申诉，无第二人保持待复核。

管理身份aal1只引导MFA，权限投影为空；业务同时核当前正式grant、新签名aal2及官方Auth session/factor/AMR，旧JWT不因数据库状态升级获权。近期stepup绑定actor/session/environment与精确动作摘要、短期一次，当前资格始终再核。首管理员bootstrap仅私有运维、每环境一次，撤权不重开，无HTTP自授入口。

后台浏览器固定调用`/api/management/*`，BFF服务端加密HttpOnly/SameSite=Strict cookie持官方token，生产Secure；写接口同源JSON与CSRF，服务端HMAC等适用密码防护继续。刷新只向core发私有refresh，不携可能过期access；取新access后重核当前管理资格。客户端不携核心密钥/角色或任意upstream。手机号TOTP内部不可投递标签不是新增邮箱身份或邮箱验证。

备用用户名密码、验证码与忘记密码默认关闭；未初始化真实账号/完整端到端验证不能宣称可用，忘记密码仅申请受理。必要OTP后台`/dashboard/configuration/otp`仅六项现有key，完整bundle预览不丢其他namespace，当前权限/官方MFA/动作摘要/registry与CAS再核后原子激活。回滚取历史OTP值生成新版本，不复活旧全bundle，不清历史限流或旧challenge预算。成功/unknown通过合法operation查询，不重复外部验证。其余配置语义见[configuration](configuration.md)。

## 正式资料的版本与适用

社区规则、隐私、条款、处理告知和帮助由专门action/type/scope授权录入、版本列表、草稿CAS、ready、预览、发布与撤下；不新增角色，也不让普通运营/AI运维默认有政策发布权。正式正文用户提供，合成只用于隔离验证；功能仍须完整，不把文案待提供作为功能未设计理由。

ready正文不可原地改，release绑定revision/digest/环境/入口/用途不可变；发布/撤下当前状态、激活指针和审计原子一致，生产另具体版本确认。发布未知先查原结果；撤下不自动回退旧版，需正常新release。注册条款、AI告知与approved_help_version来自真实release，不用配置字符串或模板绕发布。

注册提交重核当前版本集合与本人明确动作，admission/receipt原子绑定。presented、acknowledged、consented是不同真实事实，不声称用户实际读完，不拿页面打开/服务器重试制造同意；相同版本/用途有效记录可引用，不新增老用户每次登录或普通公开AI每次点击规则。self/草稿主动确认仍按已批要求，源资格及作者用途另核。

公共读取仅当前入口已发布/允许版本，合法superseded历史明确is_current=false；prepared/withdrawn/未来或NULL发布时间/非ready正文不可读。当前published须匹配active指针；App会话仅app、share-read仅share，admin不借公共文档audience扩权。原注册集合/age版本读取兼容保持；集合不截断伪完整，超过上限真实不可用、空集合无结果，GET不写同意。条款缺失仅阻塞新注册，告知缺失仅阻塞该用途新AI发送，帮助缺失如实提示，不关无关合法功能。

## 插件、开发环境与发行

受邀开发者只提交包，不自审/安装/启用；同人也分步骤审具体digest、权限增量、依赖与迁移。安装/检查/installed-disabled/enabled分开，sandbox运行许可不等测试或生产安装。依赖默认阻止，联动仅明确安全集合停用，不能自动卸载或额外清数据。历史、保留、升级、卸载、重装和额外永久purge分别预览/结果/授权，见[SDK](plugin-sdk.md)。

扩展descriptor/注册action仍核host兼容、安装epoch、当前用户/环境/原模块资源资格；不接任意SQL或给原始Storage旁路。开发sandbox限时隔离合成数据/凭据，正式工具/样例/文档完整交付仍保留，当前未实现部分真实不可用。

生产发行/迁移/权限/版本生效与扩大明确名单各需当前超管/MFA/具体摘要确认；Actions只得短时动作限定租约，构建/检查通过不自动部署。只读发行/审计结果是真状态，同版产物/迁移/config/runtime/名单与恢复限制关联，失败/取消/unknown不改成通过。不存在通用全库导出端点；秘密变更仅受控secret_ref，不返回原密钥。详见[release](release-evidence.md)。

## 分享只读与逐路由用途

分享网页`/p/{stable_id}`、`/u/{account_id}`、`/t/{thread_id}`逐请求SSR当前核。公开有效目标200仅合法元信息；非公开但当前有权的登录用户200/no-store/noindex，正文/媒体仅向本人投影。匿名受限只给不泄存在的登录提示/占位或统一404；登录无权/已删/失效统一404或安全占位，不能将全部受限目标一律404。

关闭收录不改人的合法读取：账号与目标策略及实际输出依赖取交集，立即X-Robots-Tag/meta noindex、退出sitemap/主动收录/可收录预览；异步更新不保证外部缓存即时消失。robots不是授权，SSR不能service_role读出后跳过用途投影。

以下是完整产品允许的share-read用途边界，精确方法/路径仍由固定OpenAPI的audience声明维护；当前未实现者不得自动开放：

| 路由族 | 唯一合法用途 |
| --- | --- |
| auth challenge/verify/refresh/logout | 必需分享login上下文，只签发/保持/撤销share-read；不兑换邀请码或注册/换号，不切App/后台audience |
| profiles及其contents | 主页当前合法公开/有权内容；无本人管理、草稿/收藏/私人历史或关系明细 |
| posts/comments/threads | 当前分享目标及合法正文/讨论/串，无作者管理revision |
| poll results | 仅目标关联投票，当前读权与投票中已投/结束规则，不在网页投票 |
| media GET/HEAD | 仅目标合法绑定正文/资料及派生，逐Range/conditional核；本人也不读草稿/私信/证据/AI附件 |
| config/effective | 固定分享UI非敏感平台默认；不附账号preferences，不用query扩后台/私人/secret |
