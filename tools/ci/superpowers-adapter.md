# 临时适配协议（ED-22）

输入为当前canonical tasks、宪法5.0.0、spec与plan。适配器只在H盘项目临时目录生成，不形成另一份规划或完成依据。

未勾选T###映射为Task N，保留原ID及真实功能、接口和安全要求。按可用业务批次实施／测试／审查，日常仅目标和直接受影响回归；是否逐行为TDD由执行者判断。关键权限、安全、数据完整性及缺陷修复须有效测试。

环境满足当前功能即推进，不等待无关公共工程；Actions按需复验。历史红链认证、准入收据、重复报告校验和归档回读不作日常门槛。任务按实际实现和对应测试更新，局部进展与未决验证分列，完整范围完成才勾选。保留真实结果和必要日志，raw工具状态不代表产品通过。
